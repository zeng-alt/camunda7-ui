# camunda7-ui — agent instructions

## Build & dev

```sh
pnpm dev       # vite dev — serves root index.html -> playground/main.ts
pnpm build     # vue-tsc --build (type-check) + vite build (lib) in parallel
pnpm format    # oxfmt src/ — no semicolons, single quotes (see .oxfmtrc.json)
```

## Architecture

- **Library entry**: `src/index.ts` — exports `virtual:uno.css` side-effect + all components
- **lib build**: vite lib mode, output `dist/camunda7-ui.{es,umd}.js`, `dist/camunda7-ui.css`, `dist/index.d.ts`
- **Playground** (dev only): `playground/main.ts` + `playground/App.vue` — imports via `camunda7-ui` package name (alias resolves to `./src/index.ts`)
- **Path aliases**: `@/` → `./src/`, `~/` → root, `camunda7-ui` → `./src/index.ts`
- **Externals** (not bundled): `vue`, `naive-ui`, `vue-i18n`, `@vueuse/core`

## CSS & UI framework

- **Compact theme** — all components use tight spacing (p-8~12, gap-4~8, text-12~14) for dense content layout. Default NaiveUI theme overridden via `themeOverrides` on `CamundaConfigProvider` to reduce padding/margin.
- **CSS** uses **Tailwind CSS** utility syntax via UnoCSS `presetWind3` (presetAttributify + presetIcons + presetRemToPx, baseFontSize:4). Custom theme colors: `primary`, `dark`, `light_border`, `dark_border`. Built-in shortcuts: `auto-bg`, `wh-full`, `f-c-c`, `card-border`, etc. — defined in `uno.config.ts`
- **UI components** use **NaiveUI** — auto-imported via unplugin-vue-components/NaiveUiResolver (no manual import needed)
- `vue` APIs also auto-imported via unplugin-auto-import

## Internationalization (i18n)

- All display text in components must use `useCamundaI18n` composable from `src/locales/index.ts` instead of hardcoded strings
- Usage: `const { t } = useCamundaI18n()` then `t('namespace.key')`
- Locale files: `src/locales/zh.js` and `src/locales/en.js`, nested under namespaces matching component/path (e.g. `bpmnPanel.general.name`)
- `CamundaConfigProvider` propagates locale via `locale` prop; integrates with NaiveUI locale internally
- No `vue-i18n` — use the built-in lightweight `t()` / `useCamundaI18n()` from `src/locales`

## BPMN Properties Panel

- Each element type has a `*PropertiesPanel` (e.g. `TaskPropertiesPanel`) containing `NTabs` with direct `NTabPane` children.
- Extra fields are delegated to `*ExtraFields` components (e.g. `UserTaskExtraFields`). They must **not** wrap `NTabPane` themselves — NaiveUI's `NTabs` requires `NTabPane` to be a direct child.
- Each `*ExtraFields` component exports a `tabs: ExtraFieldTab[]` array (type from `src/components/bpmn-panel/base/index.ts`):

```ts
export const userTaskTabs: ExtraFieldTab[] = [
  { name: 'userTask', labelKey: 'bpmnPanel.tabs.userTask' },
]
```

- The PropertiesPanel imports the tabs array and maps over it to generate direct `NTabPane` wrappers:

```tsx
{type === 'user-task' && userTaskTabs.map(tab => (
  <NTabPane name={tab.name} tab={t(tab.labelKey)}>
    <UserTaskExtraFields ... />
  </NTabPane>
))}
```

This pattern supports ExtraFields with multiple tabs — just add more entries to the exported array.

## Key tooling

- **Type declarations**: generated by `vite-plugin-dts` using `tsconfig.app.json`
- **Formatter**: `oxfmt` — enforces no-semicolon + single-quote style

## Publishing (npm)

- Package is public (`"private": false`) with `"publishConfig": { "access": "public" }`
- Only `dist/` is published (see `"files"` in package.json)
- Consumers import: `import { ... } from 'camunda7-ui'` and `import 'camunda7-ui/style.css'`

## Conventions

- TypeScript strict with `noUncheckedIndexedAccess`
- Vue 3 `<script setup lang="ts">` + JSX support
- `playground/` excluded from tsconfig — uses its own `playground/tsconfig.json` extending `tsconfig.app.json`
- `test-app/` is legacy, `playground/` is the active test environment
